# 2026-09-30-decode-br-lines: Decode: keep <br> so sulguk renders line breaks

## Context

Users report the bot "Decode" button renders XDR decode output as one blob
without line breaks (regression since 2026-09-14). Root cause: commit c29fc2e
added `_sanitize_decode_html` in `bot/other/web_tools.py`, which replaces
`<br>` with bare `\n`; the message is sent with `parse_mode=SULGUK_PARSE_MODE`
(`bot/routers/sign.py:1242`), and sulguk (HTML parser) renders bare `\n` in
text nodes as a space (verified by rendering through sulguk Transformer:
`"Line1\nLine2"` → `'Line1 Line2'`, while `"Line1<br>Line2"` → newline kept).
The site (eurmtl.me `routers/remote.py:74`) joins lines with `<br>` and is not
at fault.
